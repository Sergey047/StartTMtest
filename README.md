# СтартТМ --- краткая инструкция пользователя

**СтартТМ** --- приложение для подключения к корпоративной сети,
необходимой для работы служебных приложений.

## Установка

1.  Скачайте актуальный APK-файл СтартТМ.
2.  Откройте APK на Android-устройстве и установите приложение.
3.  Если Android запросит разрешение на установку из этого источника ---
    разрешите его.

## Первая активация

1.  Запустите СтартТМ.
2.  Выберите свою фирму/подразделение.
3.  Введите полученный у администратора **код-пароль**.
4.  Выполните активацию.
5.  При первом запуске VPN подтвердите системный запрос Android на
    создание VPN-подключения.

> Для первой активации может потребоваться подключение к Wi-Fi.

После успешной активации повторно выбирать фирму и вводить код при
каждом запуске не требуется.

## Подключение

Нажмите **СТАРТ** и дождитесь состояния **«Подключён»**. После этого
можно пользоваться рабочими приложениями, для которых требуется
корпоративная сеть.

Для отключения VPN **удерживайте кнопку СТОП** до завершения отключения.

## Проверка соединения

После запуска VPN проверка становится доступна примерно через **60
секунд**.

Нажмите **«Проверить соединение»**:

-   **«Соединение установлено»** --- VPN-соединение работает;
-   **«Нет соединения»** --- соединение через VPN в данный момент не
    установлено.

Повторную проверку можно выполнить через 60 секунд.

## Обновление подписки

Рекомендуется обновлять подписку **перед началом рабочей смены**,
желательно при стабильном Wi-Fi-соединении.

Если обновить подписку не удалось:

1.  Выберите ранее работавшую конфигурацию.
2.  Нажмите **СТАРТ**.
3.  Дождитесь подключения VPN.
4.  Повторите обновление подписки.

## Повторная авторизация

Если сохранённый код-пароль больше недействителен, появится экран
**«Требуется повторная авторизация»**.

Получите новый код-пароль у администратора своей фирмы, введите его и
нажмите **«Авторизоваться»**.

После **3 неверных попыток** ввод кода временно блокируется на **3
минуты**.

## Если возникли проблемы

1.  Проверьте наличие интернета.
2.  Попробуйте другую доступную конфигурацию.
3.  Выполните **«Проверить соединение»** после подключения.
4.  При необходимости обновите подписку.
5.  Если проблема сохраняется --- обратитесь к администратору своей
    фирмы.
